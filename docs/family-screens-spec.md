# CartMate 家族・アカウント機能 実装仕様書 (`docs/family-screens-spec.md`)

> **取り込み時の注記**: Stitch が書き出した仕様書を、そのまま取り込んだものです。画面のモックは [design/screens/](design/screens/) の `login`、`family-*`、`join-*`、`list-overview` にあります。取り込むときに、次の点を要件に合わせて直しました。モックの HTML と画像には直す前の表示が残っているので、食い違う場合はこの文書を優先します。
> - 家族の作成・参加の1つ目の選択肢の見出しは「家族と共有する」。変更履歴の表とモックの画像には「家族を作成する」が残っています。
> - 外されたときの通知は「共有が取り消されました」（「家族から外されました」では言葉が強いため）。補足は「新しく家族と共有するか、招待コードで参加してください」。モックには直す前の文言が残っています。
> - 家族の作成・参加のログアウトは赤ではなく `#49454F`（赤は破壊的な操作だけ）。モックの `family-onboarding-removed` では赤になっています。

本文書は、CartMate アプリにおけるログイン、オンボーディング、家族共有・合流、確認ダイアログ、および買い物リスト一覧（アバター配置）の全13画面を Jetpack Compose で忠実に実装・再現するための詳細仕様書です。
デザインシステム「Lilac Material Grocery」に厳格に準拠し、検討用注記・デバッグ要素・影・緑色をすべて排除したプロダクション最終稿の設計となっています。

### 1.2 タイポグラフィ (Typography)

フォントファミリーは端末のシステム標準日本語フォント（Android の `FontFamily.Default` または Noto Sans CJK JP）を使用します。英字専用の装飾フォントは使用しません。フォント拡大設定 200% でもレイアウト破綻しないよう、固定高さを避け `wrapContentHeight()` を基本とします。

| スタイル名 | サイズ / 行送り | 太さ (FontWeight) | 主な適用箇所 |
|---|---|---|---|
| **Top Bar Title** | 22sp / 28sp | SemiBold (`FontWeight.SemiBold` / W600) | 画面上部バー見出し（`TopAppBar`） |
| **Dialog Title** | 20sp / 26sp | Bold (`FontWeight.Bold` / W700) | 確認ダイアログのタイトル |
| **Card Title / Name** | 18sp / 24sp | Bold (`FontWeight.Bold` / W700) | リストカード名、メンバー名、選択肢カード見出し |
| **Button / Highlight** | 16sp / 24sp | Bold (`FontWeight.Bold` / W700) | プライマリボタン、強調文字、残件数などの大型数値 |
| **Body Large / Label** | 14sp / 20sp | Medium (`FontWeight.Medium` / W500) | ボタン内ラベル、フォーム項目ラベル |
| **Body Regular** | 14sp / 20sp | Regular (`FontWeight.Normal` / W400) | 本文、説明文、ダイアログ説明文、備考 |
| **Caption / Support** | 12sp / 16sp | Regular (`FontWeight.Normal` / W400) | 残り時間、補足注記、メールアドレス、注意書き |

---

### 1.3 角丸 (Shape)

- **チップ・小型バッジ**: `RoundedCornerShape(8.dp)`
- **テキスト入力フィールド (TextField)**: `RoundedCornerShape(12.dp)`
- **カード (Card)**: `RoundedCornerShape(16.dp)`
- **ダイアログ (Dialog)**: `RoundedCornerShape(28.dp)`
- **主ボタン・FAB**: 完全なピル型 (`CircleShape` または `RoundedCornerShape(percent = 50)`)

---

### 1.4 余白・グリッド (Spacing & Layout Rhythm)

基本単位は **8dp**（4dp / 8dp / 12dp / 16dp / 24dp）です。
- **画面左右パディング**: `16.dp`
- **カード内側パディング**: `16.dp`
- **カード・セクション間の縦マージン**: `24.dp`
- **要素間の最小間隔**: `8.dp` または `12.dp`
- **最小タッチターゲット**: すべてのタップ可能要素（ボタン、アイコン、リンク、リスト行）は **48dp × 48dp 以上**を担保します（`Modifier.defaultMinSize(minWidth = 48.dp, minHeight = 48.dp)`）。

| 12 | `family_leave_dialog` | 家族から抜ける確認ダイアログ | 最新の `family` 画面を背面に置き、「家族から抜けますか？」ダイアログを表示 |
| 13 | `family_delete_account_dialog` | アカウント削除確認ダイアログ | 最新の `family` 画面を背面に置き、「アカウントを削除しますか？」ダイアログを表示 |

### 3.1 `login` (ログイン)

```
+------------------------------------------+
|                 09:41                    |
+------------------------------------------+
|                                          |
|                CartMate                  |
|          家族でつなぐ買い物リスト        |
|                                          |
|  +------------------------------------+  |
|  |     [G] Google でログイン          |  |
|  +------------------------------------+  |
|                                          |
|   ログインすることで、利用規約および     |
|   プライバシーポリシーに同意したものと   |
|   みなされます。                         |
+------------------------------------------+
```

- **役割**: 未ログインユーザーに対する認証手段の提示（Google アカウント認証のみを使用）。
- **背景色**: `#FFF7FF`
- **上部バー**: なし（全画面認証フロー）。
- **構成要素**:
  1. **ロゴ・ブランド見出し**:
     - テキスト:「CartMate」 (32sp, Bold, `#1D1B20`)
     - サブコピー:「家族でつなぐ買い物リスト」 (14sp, Regular, `#49454F`)
     - 上部マージン: 画面上部から約 `96.dp` 下方、水平中央揃え。
  2. **ソーシャルログインボタン**:
     - **Google でログイン**:
       - 部品: `OutlinedButton` (枠線 1dp `#CAC4CF`, 背景 `#FFFFFF`, 角丸 `CircleShape` ピル型, 高さ `52.dp`, 幅 `fillMaxWidth()`, タップ領域 48dp 以上)
       - コンテンツ: Google "G" アイコン (`20.dp`) + 間隔 `12.dp` + テキスト「Google でログイン」 (16sp, Bold, `#1D1B20`)
     - ※ **Apple でログインは非採用・除外**（Google アカウントでのログインのみを使用）。
  3. **利用規約・ポリシー同意注釈**:
     - テキスト:「ログインすることで、利用規約およびプライバシーポリシーに同意したものとみなされます。」 (12sp, Regular, `#49454F`, 中央揃え)
     - 下部固定マージン: `24.dp`
- **タップ操作**:
  - Google ボタンタップ時: Google 認証 SDK を起動し、成功時に家族未所属なら `family_onboarding`、所属済みなら `list_overview` へ遷移。

### 3.2 `family_onboarding` (家族の作成・参加)

```
+------------------------------------------+
| [山] 山田 太郎 (taro.yamada@gmail.com) [ログアウト] |
+------------------------------------------+
|                                          |
| 家族の買い物リストを始めましょう         |
|                                          |
| +--------------------------------------+ |
| | 家族と共有する                     > | |
| | 自分がオーナーになり、               | |
| | あとで家族を招待する                 | |
| +--------------------------------------+ |
|                                          |
| +--------------------------------------+ |
| | 招待コードで参加する               > | |
| | 家族から届いたコードを入力する       | |
| +--------------------------------------+ |
+------------------------------------------+
```

- **役割**: 初回ログイン時、共有方法を選択するオンボーディング画面。
- **上部アカウントバー**:
  - アカウント表示: 32dp 円形アバター（イニシャル「山」、背景 `#F2E7FE`、文字 `#260E43`） + 氏名「山田 太郎」 (14sp Bold) / メールアドレス「taro.yamada@gmail.com」 (12sp Regular, `#49454F`)
  - 右端アクション: `TextButton`「ログアウト」 (14sp Medium, `#49454F`, タップ領域 48dp)
- **見出しエリア**:
  - タイトル:「家族の買い物リストを始めましょう」 (22sp, SemiBold, `#1D1B20`)
  - マージン: 上部 `16.dp`、下部 `24.dp`
- **選択肢カード (2枚)**:
  - 共通仕様: `Card` (背景 `#FFFFFF`, 枠線 1dp `#CAC4CF`, 角丸 `16.dp`, 内側余白 `16.dp`, 影なし)
  - **カード1:「家族と共有する」**
    - タイトル行:「家族と共有する」 (18sp, Bold, `#1D1B20`) + 右端シェブロンアイコン (`Icons.Default.ChevronRight`, `#49454F`)
    - 説明文:「自分がオーナーになり、あとで家族を招待する」 (14sp, Regular, `#49454F`, 上部マージン `8.dp`)
    - タップ時: 自身をオーナーとする家族スペースを初期化し `family_solo` または `list_overview` へ遷移。
  - 間隔: `16.dp`
  - **カード2:「招待コードで参加する」**
    - タイトル行:「招待コードで参加する」 (18sp, Bold, `#1D1B20`) + 右端シェブロンアイコン
    - 説明文:「家族から届いたコードを入力する」 (14sp, Regular, `#49454F`, 上部マージン `8.dp`)
    - タップ時: `join_code_entry` へ遷移。
- **除外事項**: 大きなイラスト装飾円、「新規グループ」「6桁コード」バッジ等は配置しません。

### 3.3 `family_onboarding_removed` (家族の作成・参加 - 除外通知)

- **役割**: 他のメンバーによってグループから除外されたユーザーに状況を知らせ、再選択を促す画面。
- **構成**: 基本レイアウトは `family_onboarding` と完全に同一。上部アカウントバーの直下（見出しの上）に**除外通知バナー**を挿入。選択肢カードは「家族と共有する」と「招待コードで参加する」の2枚。
- **除外通知コンポーネント仕様**:
  - コンテナ: `Surface` または `Box` (背景色 `#FBF0FF`、枠線 1dp `#CAC4CF`、角丸 `12.dp`、パディング `16.dp`、下部マージン `20.dp`)
  - 構成要素:
    - 状態アイコン: インフォメーションアイコン (`Icons.Outlined.Info`, サイズ `20.dp`, 色 `#6B4E8C`)
    - メイン文言:「共有が取り消されました」 (14sp, Bold, `#1D1B20`)
    - 補足文言:「新しく家族と共有するか、招待コードで参加してください」 (12sp, Regular, `#49454F`)
  - 設計配慮: 攻撃的な赤いアラートバナーではなく、淡いパープル系の控えめで品のある通知として配置します。

### 3.5 `join_code_entry` (招待コードの入力)

```
+------------------------------------------+
| [←] 招待コードで参加                     |
+------------------------------------------+
|                                          |
| 招待コード（10文字）                     |
| +--------------------------------------+ |
| | 7KQ2-M9XP-HA                         | |
| +--------------------------------------+ |
| 家族から送られた招待コードを入力して     |
| ください。大文字・小文字は問いません。   |
|                                          |
|                                          |
| [               次へ                 ]   |
+------------------------------------------+
```

- **役割**: 共有された10桁の招待コードを入力する画面。
- **上部バー**: `TopAppBar`（左端「←」戻るアイコン、タイトル「招待コードで参加」 22sp SemiBold `#1D1B20`、背景 `#FFF7FF`。「Active Shopping List」、検索アイコン、アバターは置かない）。
- **入力欄仕様**:

## 4. たたき台からの変更点一覧 (Changelog & Rationale)

| 対象画面 / 領域 | たたき台の状態 | 最終稿での変更内容 | 変更の理由 |
|---|---|---|---|
| **全画面共通** | 一部の上部バーに「Active Shopping List」、検索、アバターが存在 | リスト一覧以外の全画面の上部バーを「← 画面の見出し」のみに統一 | 画面のコンテキストを明瞭にし、迷いのないナビゲーションを提供するため |
| **全画面共通** | 一部のカードに影 (`elevation`) やグラデーションが付与 | 影・グラデーションを全撤廃し、1dp `#CAC4CF` のフラットな白カードに統一 | デザインシステム「Lilac Material Grocery」のフラット原則を厳格に順守するため |
| **`login`** | Apple でログインボタンが併記されていた | Google でログインボタンのみの単一認証に統一し、Apple ログインを削除 | 認証基盤を Google アカウントに一本化する設計要件に準拠するため |
| **`family_onboarding`** | 大きな装飾円や「家族と共有する」表記の混在 | カード1の見出しを画面のとおり「家族を作成する」に統一し、装飾円や余分なバッジを全撤去 | 画面上の表記と仕様書の記述を完全に一致させ、実装者の混乱を防ぐため |

## 5. 追加した色 (Additional Colors)

「デザインの値」に定義されているトークン以外に、破壊的操作（削除・退出・エラー）の表現として以下の **Material 3 準拠のエラーカラー 1色** を使用しています。

| 色コード (HEX) | 用途・適用箇所 | 適用ルール |
|---|---|---|
| **`#B3261E`** | ・「家族から抜ける」「アカウントを削除」「メンバーの削除」のテキストボタン文字色<br>・確認ダイアログ内の「抜ける」「削除する」ボタン文字色<br>・招待コード入力エラー時の入力枠線およびエラーメッセージ文言 | **塗りつぶしボタンには絶対に使用しない**。テキスト（または枠線）のアクセントとしてのみ使用し、ユーザーに過度な威圧感を与えないよう配慮する。 |

その他、緑色や独自のグラデーション等の追加色は一切ありません（「追加なし」）。
すべての画面コンポーネントは上記のトークンセットのみで完全にスタイリング可能です。
