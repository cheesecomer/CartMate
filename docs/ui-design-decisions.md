# CartMate UI/UX 設計決定事項ドキュメント (`docs/ui-design-decisions.md`)

本作書は、Android ネイティブ買い物リスト共有アプリ「**CartMate**」のプロトタイピングおよびデザイン検討プロセスにおいて合意・決定された UI/UX 仕様、設計方針、変更履歴、および Jetpack Compose 実装上の考慮事項をまとめた技術・デザイン決定記録（ADR / Design Decision Record）です。

---

## 1. 最終的に採用したデザイン方針

### 1.1 全体デザインコンセプト・基本思想
- **「自宅でのリスト作成」と「店内での消し込み・片手操作」の両立**
  - リスト作成の主戦場は「自宅（冷蔵庫・パントリーのチェック時や献立を考える時）」であると定義。テンポよく連続入力できるキーボード・Enter主体の高速登録体験を追求。
  - 店舗内では片手操作・歩行中・カゴ持ちを想定し、画面下部への重要操作配置、適度なタップターゲット（最低48dp基準）、高いコントラストと視認性を確保。

### 1.2 配色・カラーパレット（Design System: Lilac Material Grocery）
Material Design 3 (M3) の Dynamic Color / Lilac & Lavender Purple パレットを基準に設計。
従来のボタニカルグリーンから、上品でやさしく清潔感のあるライラックパープルに全面刷新。完了表示を含め緑を完全に排した**「ライラック・パープル系統一」**を正式採用。

- **Primary / Accent**: `#6B4E8C`（主要CTA、確定ボタン、進捗バー、チェック完了マーク、FAB等に適用）
- **Primary Container / Badge**: `#F2E7FE`（チェック完了バッジや数量ピル、強調コンテナ）
- **Badge Variant**: `#E8DEF8`（補助バッジ、補助チップ）
- **Surface**: `#FFF7FF`（アプリ全体、アプリアイコン背景、スプラッシュ画面背景と完全一致させた淡色ライラック。Android 12+ SplashScreen とのシームレスな起動遷移を保証）
- **Surface Container Lowest / Low / High**: `#FFFFFF`, `#FBF0FF`, `#E1D6E7`（境界線を過度に使わず、面とトーンの階層で要素を区切る）
- **Text & Content**: 高コントラストなダークパープル/チャコール系（`#1D1B20` / `#49454F`）。購入済み（チェック済み）は `40%〜50%` の不透明度へ減光＋打消し線。
- **完了・チェック表示の色彩設計**: 緑を完全に排し、ディープパープル（`#6B4E8C`）とソフトライラックトーンに統一。

### 1.3 アプリアイコンと起動遷移（SplashScreen）
- **背景**: アプリ本体の背景と同一の淡色（`#FFF7FF`）を採用。
- **シンボル**: ブランドカラーであるパープル（`#6B4E8C`）のショッピングカート＋チェックマーク。
- **Android 12+ 適合性**: ホーム画面からタップした際、アイコン背景がそのままスプラッシュ画面へ広がり、明暗の反転やフリッカーなく自然にアプリ本体へ遷移する。

## 3. レビューで指摘した問題と対応結果

### 3.1 ライラック配色における緑の浮き
- **指摘内容**: パレットをライラックパープルに変更した際、従来の「チェック完了＝緑」が補色関係により悪目立ちし、浮いて見えていた。
- **採用した改善案**: 
  - 完了バッジ・プログレスバー・チェックマークに至るまで **ディープパープル（`#6B4E8C`）** および **ソフトライラックコンテナ** に統一。
  - 画面内の色数を最小限に絞り込み、統一感と上品な洗練度を最大化。

### 3.2 アプリアイコンと Android 12+ スプラッシュ画面の整合性
- **指摘内容**: アイコンが濃色背景だと、スプラッシュ展開からアプリ画面（淡色）に切り替わる際に明暗のフリッカーが生じる。
- **採用した改善案**: 
  - アイコン背景をアプリ背景（`#FFF7FF`）と同一の淡色とし、シンボルをパープル（`#6B4E8C`）にする構成を採用。Google純正アプリと同等のシームレスな起動トランジションを実現。

### 3.3 公開範囲引き継ぎの最新確定ルール
- **指摘内容**: 当初「Enter即追加時は常に共有」としていたが、プライベート設定を意図した商品追加の連続性に対応できていなかった。
- **採用した改善案**:
  - 各リストにおいて、直前に選択・登録した公開範囲（共有またはプライベート）をメモリ・セッション値として保持し、Enter即追加およびサジェスト「＋」即追加時にもそのまま引き継ぐ仕様に修正。

## 4. 画面ごとの最終仕様（採用6画面）

### 4.1 買い物リスト一覧画面（`list-overview` / `SCREEN_79`）
- **Top App Bar**: アプリ名「CartMate」と、右端に自分のアカウントのアバター（タップで家族画面）。
- **上部ヒント**: 「長押しで並び替えができます」（アイコンなしテキストのみ）。
- **リストカード群（2カラム）**: リスト名、のこり件数/完了件数のプログレス（パープル系）、プライベート時のみ鍵アイコン。
- **FAB**: 「＋ リスト作成」（Primary `#6B4E8C`, Pill型）。

### 4.2 買い物リスト一覧 空状態（`list-overview-empty` / `SCREEN_103`）
- **レイアウト**: 画面中央配置。
- **メッセージ**: 「リストがありません」＋「最初の買い物リストを作成しましょう」。
- **CTA**: 「＋ リストを作成する」ボタン。

### 4.3 買い物リスト一覧 オフライン（`list-overview-offline` / `SCREEN_124`）
- **バナー**: Top App Bar 直下に固定「オフライン表示中（変更は再接続時に同期されます）」（背景 `#FCEEE8` / テキスト `#6E3917`）。
- **操作性**: キャッシュ済みリストカードの閲覧・操作が可能。デバッグ用トグル等は設置しない。

### 4.4 買い物リスト詳細画面（`list-detail` / `SCREEN_210`）
- **Top App Bar**: 戻るボタン、リスト名（「スーパー」）。プライベート時は鍵アイコン。
- **コンテンツ部**: 進行状況バー（パープル系「のこり 4件 / 完了 2件」）、商品行（数量・単位強調、完了時はパープルチェック＋打消し＋40%減光、Undoボタン常設）。
- **商品追加位置**: リスト末尾（最下部）に追加。
- **ボトム入力バー**: 常設「商品名を入力して追加...」。フォーカスでサジェスト（ボトムシート型）起動。

### 4.5 商品サジェスト画面（`product-suggestions-sheet` / `SCREEN_231`）
- **形態**: ボトムシート型（背景スクリム付き、上部角丸28dp）。
- **Enterキー / 送信**: 「数量1・単位個・直前公開範囲引き継ぎ・備考なし」で即座にリスト末尾へ追加。入力欄クリアでキーボードを保持したまま連続入力。
- **最上部固定導線**: 「数量を設定して追加」（品名は入れない）。タップで商品詳細入力画面へ遷移。
- **候補行**: 「＋」タップで過去履歴条件＋直前公開範囲で即追加。テキスト部タップで詳細入力画面へ。

### 4.6 商品詳細入力画面（`product-detail-entry` / `SCREEN_236`）
- **構成**: 商品名ヘッダー、数量ステッパー＆数字入力、単位チップ＆自由入力、公開範囲（共有リスト時のみ表示、直近引継ぎ、登録時のみ設定可）、備考欄。
- **アクション**: 「リストに追加する」（確定後、リスト末尾に追加して詳細へ戻る。「続けて商品を追加する」チェックボックスは置かない）。
