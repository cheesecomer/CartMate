# CartMate 実装用デザイン仕様書 & ハンドオフドキュメント (`docs/implementation-spec.md`)

本作書は、Android ネイティブ買い物リスト共有アプリ「**CartMate**」を Kotlin / Jetpack Compose で開発・実装するための完全なデザイン・UI仕様書です。
これまでのデザイン検討・操作モック検証・合意事項をすべて反映し、不要なデモ用UIや旧デザイン（ボタニカルグリーン等）を排除した最終成果物です。

---

### 1.3 余白・グリッド（Spacing & Layout）
8dp を基本単位とする **8pt Grid System**。
- **4dp (`x-small`)**: バッジ内パディング、アイコンとテキストの隙間
- **8dp (`small`)**: チップ間隔、リスト行内の要素間隔、小カードのインセット
- **12dp (`medium`)**: フォームフィールド垂直間隔、コンパクトなカードパディング
- **16dp (`large`)**: 画面左右のマージン、カード内パディング、リスト項目間隔
- **24dp (`x-large`)**: セクション間隔、FABのマージン
- **最小タップ領域**: **48dp × 48dp**（チェック操作、ボタン、チップ等すべてに保証）

### 1.4 角丸（Shape Tokens）
- **`ShapeSmall`**: 8dp（チップ、タグ、小ボタン）
- **`ShapeMedium`**: 12dp（テキスト入力フィールド、インプットトレイ）
- **`ShapeLarge`**: 16dp（リストカード、商品カード）
- **`ShapeExtraLarge`**: 28dp（ボトムシートの上部角丸、ダイアログ）
- **`ShapeFull`**: 999dp（Pill型FAB、数量バッジ、ステッパーボタン、主要CTAボタン）

## 3. 各画面の詳細仕様と Jetpack Compose 実装手引き

### 3.1 買い物リスト一覧（`list-overview.html` / `SCREEN_79`）
- **Top App Bar**: 左にアプリ名「CartMate」、右端に自分の Google アカウントのアバター（32dp の円。48dp のタップ領域）。アバターのタップで家族画面を開く。ほかの設定アイコンや戻るボタンは置かない。
- **並び替え**: 上部案内テキスト「長押しで並び替えができます」（アイコンなし、テキストのみ）。カード面の長押しドラッグ（`detectDragGesturesAfterLongPress`）で並び替え。カード側にドラッグハンドルアイコンは置かない。
- **カード構成（2カラムグリッド）**:
  - リスト名（`TitleLarge`, 18sp Bold）
  - ※リスト自体への装飾アイコン・カテゴリ別アイコンは一切表示しない。
  - のこり件数（`LabelSmall`）および完了進捗バー（Primary `#6B4E8C` / Track `#F5EBF9`）
  - プライベート時のみ鍵アイコン（`ic_lock` 16dp）を表示（「共有」バッジは非表示）。メンバーのアバターは表示しない（2026-10-26 に変更。[ui-design-decisions.md](ui-design-decisions.md)）。
- **FAB**: 右下固定「＋ リスト作成」（Primary `#6B4E8C`, Text `#FFFFFF`, Pill型角丸9999px）。
- **リスト追加位置**: 新規作成されたリストは一覧の末尾に追加される。

### 3.2 買い物リスト一覧 空状態（`list-overview-empty.html` / `SCREEN_103`）
- **レイアウト**: 画面中央配置。
- **メッセージ**: 「リストがありません」（20sp Bold）＋「最初の買い物リストを作成しましょう」（14sp Regular）。
- **装飾**: 派手なイラストや店舗候補選択UIは置かず、クリーンなメッセージと「＋ リストを作成する」CTAボタン（Primary `#6B4E8C`）で構成。

### 3.3 買い物リスト一覧 オフライン（`list-overview-offline.html` / `SCREEN_124`）
- **バナー**: Top App Bar 直下に固定警告バナー「オフライン表示中（変更は再接続時に同期されます）」。
- **カラー**: 背景 `#FCEEE8` / テキスト・アイコン `#6E3917`。
- **操作性**: キャッシュ済みリストカードの閲覧・タップ・編集は通常通り可能。オフライン切替用のデバッグボタン・トグルは置かない。

### 3.4 買い物リスト詳細（`list-detail.html` / `SCREEN_210`）
- **Top App Bar**: ナビゲーション戻る矢印アイコン（48dpタップ領域）、リスト名「スーパー」（20sp Semi-Bold）、プライベート時は鍵アイコン。メンバーのアバターは表示しない。※コンテンツ領域内にはリスト名を重複表示しない。
- **進行状況**: 「のこり 4件 / 2完了」のバッジだけ（`#F2E7FE` 背景に `#6B4E8C` テキスト）。見出し「買い物進捗」、カードの枠、進捗バーは置かない（2026-10-26 に変更）。
- **商品行カード（購入完了・Undo仕様）**:
  - **未完了状態**: カードをタップすることで即座にチェック完了へ遷移。商品名（16sp Bold）、数量・単位ピル（`#F2E7FE` 背景、`#6B4E8C` テキスト、14sp Medium）、備考・周期メタ情報。商品ごとの装飾用アイコンは設けない。
  - **完了状態**: カード背景は薄いトーン（`#FBF0FF`）、商品名は打消し線（line-through）＋40〜50%減光、パープルチェックマーク（`#6B4E8C`）。
  - **Undo（元に戻す）**: 完了カード右側に「元に戻す」テキストボタンを常設。タップで未完了状態へ復帰。
- **商品追加位置**: 新規追加された商品は **リスト末尾（最下部）** に順次追加される。
- **ボトム入力バー**: 画面最下部に固定「商品名を入力して追加...」（フォーカスでサジェストボトムシート起動）。

### 3.5 商品サジェスト ボトムシート（`product-suggestions-sheet.html` / `SCREEN_231`）
- **形態**: **ボトムシート方式**（背面にリスト詳細画面が透けて見える半透明スクリム `rgba(0,0,0,0.5)` 付きモーダルシート）。上部角丸は 28dp。全画面型は不採用。
- **キーボード連動**: IME展開時に入力欄が最上部に押し上げられ、`Modifier.imePadding()` でスムーズに追従。
- **最上部固定アクション**: 固定文言**「数量を設定して追加」**（品名は含めない）。タップで入力文字列を保持して商品詳細入力画面へ遷移。
- **候補一覧**: 「履歴」と「頻度予測」を分割せず、1つのフラットな「候補」リストとして表示。
- **候補行アクション**:
  - テキスト部分タップ: 該当候補のデータを引き継いで商品詳細入力画面へ進む。
  - 右側の「＋」アイコンボタンタップ: 過去履歴の数量・単位、および**「当該リストで直前に選択した公開範囲」**を引き継いで即座にリスト末尾へ追加。
- **Enterキー / 送信による即追加と連続入力（重要確定仕様）**:
  - 入力中文字列を「数量: 1」「単位: 個」「備考: 空」「公開範囲: **当該リストで直前に選択した公開範囲を引き継ぐ**」で**即座にリスト末尾へ追加**。
  - **ボトムシートは閉じず**に入力欄が自動クリアされ、ソフトウェアキーボードを開いたまま連続して次の品目をテンポよく入力可能。

### 3.6 商品詳細入力（`product-detail-entry.html` / `SCREEN_236`）
- **構成**:
  - ヘッダー: 「×」閉じる/戻るアイコン（48dpタップ領域）、タイトル「商品の詳細入力」（20sp Semi-Bold）。
  - 追加先リスト表示: 「追加先: スーパー（共有リスト 3人）」。
  - 商品名ヘッダー: 編集可能（18sp Bold）。
  - 数量入力: 大きな数字表示（24sp Bold）＋ ステッパーボタン（`−` / `＋` 48dp×48dp、`＋`は Primary `#6B4E8C`）。
  - 単位選択: チップ群（「個」「本」「パック」「袋」＋ 自由入力欄）。
  - **公開範囲設定（重要）**:
    - **共有リスト時**: 「全員に共有」「自分のみ（プライベート・鍵アイコン）」の選択チップを表示。現在選択されている公開範囲を表示し、直近の選択値を初期値として引き継ぐ。注記「※ 登録後に公開範囲を変更することはできません」。
    - **プライベートリスト時**: 公開範囲選択UIは非表示（全商品プライベート固定）。
  - 備考欄: 複数行テキスト入力（OutlinedTextField）。よく使うメモ候補チップ。
- **アクション**: 最下部「リストに追加する」（Primary `#6B4E8C`, Pill型）。**「続けて商品を追加する」チェックボックスは完全に撤廃**。確定後は入力内容を反映してリスト末尾に追加し、リスト詳細画面へ戻る。

## 4. 公開範囲の引き継ぎ仕様（重要）

公開範囲は **リストごとに保持** されます。

### 4.1 共有リスト内の挙動
1. **初期値**: 初回の商品追加では「共有」を初期値とする。
2. **詳細入力での変更**: 詳細入力画面で「自分のみ（プライベート）」に切り替えて登録した場合、そのリストにおける次回以降の商品追加も「プライベート」が初期値となる。
3. **Enter即追加での引き継ぎ**: サジェストでのEnter即追加は、**直前に選択された公開範囲（共有またはプライベート）をそのまま引き継いで登録**する。
4. **候補「＋」での引き継ぎ**: サジェスト候補の「＋」タップによる即追加も、直前の公開範囲を引き継ぐ。
5. **「共有」への復帰**: 詳細入力で「全員に共有」を選んで登録した場合、以降の即追加も共有を引き継ぐ。
6. **プライベート商品の可視性**: 共有リスト内のプライベート商品は、登録した本人にのみ表示され、鍵アイコンが付与される。

### 4.2 プライベートリスト内の挙動
1. 全商品がプライベート固定。
2. 商品詳細入力画面に公開範囲選択UIは一切表示しない。
3. Enter即追加および「＋」即追加もすべてプライベート固定。

## 5. アプリアイコンと SplashScreen 設定

- **採用アイコン**: `Android app icon for CartMate on a solid very pale lilac off-white background (#FFF7FF)` (`IMAGE_9`)
- **背景**: `#FFF7FF`（アプリ Surface と完全一致）
- **シンボル**: `#6B4E8C`（ライラックパープルのショッピングカート＋チェックマーク）
- **Android 12+ SplashScreen 実装コード**:
  ```xml
  <!-- res/values/colors.xml -->
  <color name="splash_background">#FFF7FF</color>
  <color name="brand_primary">#6B4E8C</color>

  <!-- res/values/styles.xml -->
  <style name="Theme.CartMate.Splash" parent="Theme.SplashScreen">
      <item name="windowSplashScreenBackground">@color/splash_background</item>
      <item name="windowSplashScreenAnimatedIcon">@drawable/ic_cartmate_foreground</item>
      <item name="postSplashScreenTheme">@style/Theme.CartMate</item>
  </style>
  ```
